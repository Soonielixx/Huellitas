#  Huellitas Felices - Landing Page

Este repositorio contiene el código fuente de una landing page para "Huellitas Felices", una tienda en línea especializada en accesorios para mascotas, incluyendo collares, camas, ropa y juguetes[cite: 2, 3]. 

El proyecto fue desarrollado como parte de la **Actividad 1: Desarrollo de una Landing page**, trabajando de manera colaborativa en un equipo de 3 personas[cite: 1].

## Objetivo del Proyecto

El objetivo principal es implementar buenas prácticas de desarrollo colaborativo utilizando Git y GitHub, construyendo una interfaz web completa estrictamente con tecnologías base y sin el uso de frameworks externos (como Bootstrap o React)[cite: 1]. 

## Tecnologías Utilizadas

*   **HTML5:** Estructura semántica del sitio[cite: 3].
*   **CSS3:** Diseño responsivo (Flexbox), estilos visuales, paleta de colores y animaciones[cite: 3, 4].
*   **JavaScript (ES6):** Interactividad y validación básica del formulario de contacto[cite: 3].
*   **Git & GitHub:** Control de versiones, trabajo por ramas (branches) y colaboración en equipo[cite: 1, 3].

## 📑 Estructura de la Landing Page

La página está diseñada en una sola vista (Single Page) y contiene las siguientes secciones obligatorias a las que se puede acceder mediante la barra de navegación[cite: 1, 4]:

1.  **Inicio (Hero):** Banner principal con una llamada a la acción[cite: 4].
2.  **¿Quiénes somos?:** Descripción de la empresa y sus valores[cite: 1].
3.  **Productos / Servicios:** Catálogo en cuadrícula mostrando las categorías de accesorios[cite: 1, 4].
4.  **Contacto:** Formulario funcional para recibir mensajes de los clientes[cite: 1].
5.  **Políticas de seguridad:** Información sobre la protección de datos y pagos[cite: 1].
6.  **Requisitos técnicos:** Especificaciones recomendadas para navegar por el sitio[cite: 1].
